Everything this design uses is free and open-source. Nothing is proprietary.

Notes
- **The logo mark** is original geometry drawn for this project. You can use it freely for the project.
- **The wordmark** is Geist SemiBold converted to outlines. The OFL allows logos made from the font's glyphs. The OFL only restricts redistributing or selling the font software itself.
- If you self-host the fonts in production (recommended), ship the OFL text with the font files.
- Example people, companies and email addresses use the reserved `.example` TLD and are fictional.
