# Design

v1.1 brand notes and tokens, copied from the designer drop on 25 Oct 2026. The app does not import this folder. The live copies are:

- `src/styles/tokens.css`
- `src/styles/tokens.json`
- `src/styles/components.css`

`tailwind.config.js` here is the designer's Tailwind v3 reference. The app is Tailwind v4 and does not load it. Dark mode is the `@custom-variant` in `src/app/globals.css`.

Read [BRAND.md](BRAND.md) (colour, type, voice, components) and [READY-v1.1.md](READY-v1.1.md) before changing visual tokens. [NAME.md](NAME.md) is the naming rule: always "Inbox Bodyguard", never "Bodyguard". [CHANGELOG.md](CHANGELOG.md) is what v1.1 changed. [LICENSES.md](LICENSES.md) covers the fonts and icons.

Logos used by the app live in `public/logo/`. Do not paint page backgrounds with Jade, rose, or a green glow. Jade is an accent only.
